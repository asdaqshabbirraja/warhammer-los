# Warhammer 40K LOS Planner - Quick Guide

## 1. Choose Or Create A Game

Open **Save Game** in the sidebar.

- Select an existing game from **Choose Game**, then click **Load game**.
- Select **New game save** to start a new game.
- Use **Edit name** to rename the current save.
- Click **Save game** to save the current board, units, enemies, rulers, and planning state.

## 2. Load A Tournament Layout

Open **Layout**.

1. Pick your **Defender's Force Disposition**.
2. Pick your **Attacker's Force Disposition**.
3. Choose **Layout A**, **B**, or **C**.
4. Click **Apply Layout**.

The app will load the correct GW-style terrain layout, deployment lines, terrain features, and objective markers.

The sidebar also shows:

- **My Primary Mission**
- **Opponent's Primary Mission**

Use **Display** to show the mission cards.

## 3. Add Your Army

Open **Army List**.

Paste your Warhammer app army list into the text box, then click **Match units**.

- Matched units are shown with a green tick.
- Unmatched units can be manually assigned a base shape and size.
- Click **Create LOS markers** to add the matched units to the map.
- Use **Remove generated LOS marker(s)** if you want to clear generated markers and start again.

## 4. Use LOS Markers

Open **LOS Markers**.

Each marker can be edited individually:

- Rename the marker.
- Choose base shape: circle, oval, or rectangle.
- Set base size.
- Set LOS range, or leave blank for unlimited.
- Toggle LOS on or off using the eye icons.

Green eye = LOS on.  
Red crossed eye = LOS off.

You can drag LOS markers around the battlefield. If a marker is part of a unit, you can move the whole unit or double-click an individual model to move it separately.

## 5. Add Enemies

Open **Deploy & Enemies**.

- Click **Add enemy** to place enemy markers.
- Enemy markers change colour depending on LOS:
  - Red = visible clearly
  - Yellow = visible through one terrain footprint
  - Grey = not visible

## 6. Rulers And Deepstrike

Open **Rulers & Deepstrike**.

Use:

- **Ruler** to measure a straight distance.
- **Sticky ruler** to keep a distance line attached between models, enemies, or footprints.
- **Deepstrike** to show valid deepstrike areas around your units.

You can clear rulers with the clear buttons in the same section.

## 7. Planning Movement

Click **Planning movement** above the map.

This lets you switch between:

- Deployment
- Turn 1
- Turn 2
- Turn 3
- Turn 4
- Turn 5

Move your units in each phase to plan future positions. The app shows movement arrows and distances between phases.

## 8. Editing Or Creating Maps

Open **Create/Upload Map**.

Use this section if you want to modify layouts or create custom maps.

- **Modify Layout** lets you load an existing preset with editing enabled.
- **Upload Map** lets you upload your own map image.
- **Create Map** lets you create a blank grid.
- **Edit Layout** contains tools for adding terrain footprints, walls, light/dense terrain, objectives, and deployment lines.

For normal play, you usually do not need this section.

## 9. Basic Controls

- Drag the map to move around.
- Use the mouse wheel to zoom.
- Use **Pan map** if you want to move the board instead of objects.
- Use **Erase** to remove eligible items such as enemies, rulers, objectives, and editable layout objects.
- Use **Undo** if you make a mistake.

## 10. Recommended Workflow

1. Load or create a game.
2. Select the correct tournament layout.
3. Paste and match your army list.
4. Create LOS markers.
5. Add enemy markers.
6. Toggle LOS on for the units you care about.
7. Use rulers, sticky rulers, and planning phases to plan deployment and movement.
